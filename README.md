# onlyV · 仅看视频

**追剧时，只想安静看完这一集。**

- **网页全屏** · 按 Alt+V，视频铺满整个窗口，画面更沉浸
- **小窗播放** · 按 Alt+P，边追剧边聊天，剧停在屏幕一角
- **自动下一集** · 一集播完自动接上，不用每集手动点
- **跳过片头片尾** · 每部剧单独记住，正片直接开始
- **简单** · 两个快捷键，像开关灯一样容易

兼容各种视频网站（通用逻辑自动适配）。多语言界面（32 种语言，跟随浏览器语言）。

English: **When you binge a show, you just want to watch the show.** Web fullscreen (Alt+V) · Mini window (Alt+P) · Auto next episode · Skip intro & outro, remembered per show.

---

以下为技术文档。

## 功能

| 功能 | 说明 |
|---|---|
| 🎬 影院模式（手动） | 按 `Alt+V` 进入：隐藏播放器外的一切内容（推荐、评论、侧栏、弹窗广告…），播放器铺满浏览器窗口（网页全屏），网站原生进度条/清晰度/倍速照常可用；**默认不自动触发** |
| ⏭ 自动下一集 | 播完或到达片尾点时自动切换下一集：站点规则 → 文本启发式 → 选集列表三级定位，兼容隐藏元素 |
| ⏩ 片头片尾跳过 | 每集自动跳过片头 N 秒；到达配置的正片结束时间点时切下一集 |
| 🎛 精细配置 | 剧集规则（URL 关键字，最长优先）> 站点默认 > 全局默认；弹窗可对当前页一键创建 |
| 🌍 多语言 | **32 种语言**；默认跟随浏览器界面语言，设置页分段胶囊组手动切换、按需加载即时生效 |

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 右上角打开 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本目录 `E:\Chrome\video-purify`
4. 打开任意视频网站即可生效

## 使用

- **页内快捷键**：`Alt+V`（Mac 上即 `⌥V`）进入/退出影院模式——默认唯一的触发方式；进入时顶部显示 4 秒毛玻璃提示后自动消失
- **默认不接管**：新页面和普通标签页刷新后保持关闭；点击网页全屏开关或按 Alt+V 手动开启。开关反映当前标签页实际状态，不保存自动开启偏好；片头片尾和自动连播在手动开启后运行。
- **工具栏图标**：总开关、各功能开关、**当前页规则**（自动预填 URL；命中已有规则时可更新/删除）
- **完整设置**（右键工具栏图标 → 选项）：只有语言 + 功能开关，极简
- **语言（32 种，独立选择页）**：设置页「语言」入口行显示当前语言，点击进入专门的语言选择页——带搜索框、以各语言母语名称显示的列表（选中项高亮圆点，无勾选图标）；默认「自动」跟随浏览器界面语言；全部界面文案完整翻译，非内置语言按需加载 JSON 字典（`content/locales/*.json`，MV3 CSP 安全的 fetch + JSON.parse）

### 片头片尾配置

规则**只在工具栏弹窗中对当前页面定义**（设置页不管理规则）：

- 看某部剧时点工具栏图标 → 自动预填当前页 URL 关键字 → 填片头/片尾秒数 → 保存
- 当前页已命中规则时：弹窗预填该规则并可**更新**或**删除**（红色按钮）
- 规则长期保存（同一部剧下次打开自动生效），匹配取最长关键字
- 未配置的剧不跳过（设置页无任何片头片尾配置）

### 规则系统（三层可插拔）

**1. 内置规则（代码级）**：`content/rules/xxx.js` 文件末尾 `VP.rules.register({...})` 自注册。
新增一个站点的支持 = 新建一个文件 + manifest 的 js 数组加一行，核心代码零改动。

```js
// content/rules/example.js —— 只有通用逻辑不够用时才需要写
window.VP.rules.register({
  id: 'example',
  hosts: ['example.com'],
  playerSelector: '#player, .video-box',   // 播放器容器（可逗号分隔多个）
  nextSelector: '.next-btn',               // 下一集按钮（可选）
  videoUrlPattern: '/watch,/play',         // 视频详情页 URL 特征（可选，逗号分隔）
  // 需要复杂逻辑时用函数钩子替代上面的声明式字段：
  // findPlayer(video, doc) → 容器元素 | null
  // findNext(doc) → 可点击元素 | {url} | null
  // isVideoUrl(url) → boolean
});
```

**2. 通用兜底**：任何钩子未命中都回落到通用启发式（探测/净化/下一集），
所以**不写任何规则，绝大多数网站也直接可用**。

### 引擎解析顺序

```
内置站点规则钩子（按 host 匹配） → 通用启发式 → 失败
```

用户配置只有一种粒度：**剧集规则**（URL 关键字 + 片头/片尾秒数）——每部剧一条，
在弹窗对当前页一键创建或在设置页管理；全局默认作为未配置剧集的兜底。

设计要点：

- **不劫持播放器**：净化只是隐藏 + fixed 定位网站自己的播放器容器，控件、清晰度、弹幕均由网站原生渲染
- **CSS class 而非内联 style**：`.vp-hide { display:none !important }`，网站 JS 无法覆盖；重渲染由 MutationObserver 节流重算
- **保留链**：容器到 body 的祖先链清除 transform/clip（保证 fixed 相对视口），链外兄弟全部隐藏
- **SPA 兼容**：hook history API + 轮询兜底，切集后自动重绑片头片尾状态机

## 验证情况

**本地 mock 视频页端到端**（含 header/推荐栏/评论/悬浮广告 + 模拟 SPA 切集）：

- ✅ 自动净化 + 网页全屏（播放器 0,0,1280×800，10 个干扰元素隐藏）
- ✅ 片头跳过、片尾自动连播：16 秒连续 7 次自动换集，循环稳定
- ✅ Alt+V 切换、手动退出不被打扰、进入/退出双向防抖不闪屏
- ✅ 规则匹配优先级：最长关键字 > 站点默认 > 全局默认

**真实视频平台大扫描**（2026-11，自动化注入实测）：

| 结果 | 平台 |
|---|---|
| ✅ 净化接管成功 | YouTube（SPA 换视频保持）、Rumble、Bilibili、爱奇艺、iQ.com、芒果TV、腾讯视频、快手、AcFun、乐视 |
| ✅ 登录/付费墙页正确不误净化 | Netflix、Disney+、Prime Video、Hulu、Max、Apple TV、优酷首页（hero 轮播预览被正确排除） |
| ⚠️ 网络不可达未测 | Twitch、Kick、Pluto TV、TikTok、Dailymotion、Vimeo（Cloudflare 人机验证） |
| ⚠️ 登录墙/重定向未进入详情 | 西瓜（强制 /app）、1905（列表页正常）、CCTV/搜狐（列表页正常，详情未达） |

扫描中修复的通用缺陷：

1. YouTube 的 video 元素 rect 恒为 0 但在播放——探测放行 rect 失真的真播放器
2. 强制覆盖 video 宽高在 YouTube 上造成黑屏——改为只设 object-fit，让站点自己管理尺寸
3. 站点重建 video 元素导致稳定确认永不达成（「接管不了」的一类根因）——改按播放器**容器**判定稳定
4. 净化链切换后旧链遗留 `vp-hide` 不清除 → B 站整链 0×0 黑屏——链上元素主动清除隐藏
5. `hideFloaters` 把链上 sticky 布局祖先（B 站）误隐藏——跳过整条保留链
6. 首页 hero 轮播预览（优酷/腾讯，静音+循环+短时长）误触发接管——按 URL 特征分级门槛 + 预告位排除
7. 「下一集」列表匹配用子串 `'on'` 误中 `button` 等 class（爱奇艺匹配到广告位）——改为 classList 精确匹配

真实网站的选择器（adapters.js）随网站改版可能失效——失效时自动回落到通用启发式，基本功能不受影响；遇到定位不准的网站，欢迎在设置中调整规则或反馈选择器。

## 已知限制

- DRM/加密流（Netflix 等）只能净化页面，播放控制不受影响
- 直播站（斗鱼/虎牙等）无下一集概念，仅净化
- 部分网站对「下一集」按钮做了自定义事件绑定，dispatch click 优先于 href 跳转，个别站点可能需要更新适配器


## 独立浏览器小窗口播放

重新加载扩展并刷新视频页后，在工具栏弹窗点击「小窗口播放」。当前标签页会移入
800×500 的独立浏览器窗口，自动进入影院模式；可以拖动标题栏、拖动窗口边缘调整尺寸。
这不是系统视频画中画，网站原生播放器及控制栏仍保留，窗口默认不置顶。

小窗口右上角的「返回普通窗口」可将视频移回原窗口；原窗口已关闭时创建普通窗口。
移动标签页不主动重新加载视频。刷新或跨页换集后会恢复小窗口返回按钮。
直接关闭小窗口会关闭该视频标签页；想继续保留视频请使用「返回普通窗口」。
需要 Chrome 102 或以上；当前只处理顶层页面可识别的播放器。

回归验证：`node --test test/window-player.test.cjs`。

### 通用失败提示回归

网页全屏开关现在会检查当前页的执行结果；失败时恢复开关；开启状态仅属于当前页面，不保存为自动全屏设置。
小窗口错误会保留在弹窗中。提示区分：未检测到视频、已确认视频在 iframe 中、
存在无法读取的 iframe（仅提示可能性）、播放器未就绪，以及内容脚本未连接。
仅播放器未就绪时仍允许移入小窗口，并显示等待播放的提示。
内容脚本未连接时请从工具栏弹窗操作以查看提示；未注入脚本的页面无法响应页内快捷键。
新增提示提供中英文，其他语言缺少对应翻译时使用英文回退。

自动化逻辑回归：

```sh
node test/window-player.test.cjs
node test/diagnostics.test.cjs
```

本地浏览器回归使用 Playwright（需在外部测试环境安装依赖和 Chromium）：

```sh
node test/browser-diagnostics.cjs
```

该测试启动本地 HTTP 服务，加载实际内容脚本和弹窗页面，模拟 Chrome API 的消息响应，
验证快捷键提示、iframe 诊断、未连接提示及开关回退。它不替代加载扩展后的浏览器 API 集成测试。
手工测试页面为 `test/diagnostics-page.html`，通过 HTTP 服务访问并使用
`?case=empty`、`?case=frame`、`?case=opaque`、`?case=loading` 切换场景。


### 0.1.1 时间规则修复

“正片从 00:02:00、正片到 00:46:00”表示从第 120 秒开始，到第 2760 秒结束。
旧的 0.1.0 ZIP 仍按“距结束多少秒”解释片尾，与当前时间点界面不一致；请使用 0.1.1。
更新扩展后必须刷新已打开的视频页，才能替换页面中已注入的旧脚本。
新增 `node test/skip.test.cjs` 回归覆盖此时间组合、短视频、反向区间和换集重置。


### 0.1.2 弹窗语言修复

英文提示不再显示旧的“来自弹窗 日期”自动名称；这类规则显示 URL 匹配路径，新规则名称也使用该路径。用户自定义名称保留。
中英文生效提示使用明确的正片起止时间（HH:MM:SS），未设置结束时间时显示对应说明。
回归：`node --test test/popup-locale.test.cjs test/skip.test.cjs`。


### 操作条与播放错误提示修复

通用探测保留原视频容器，仅额外保留与视频关联的兄弟操作条或浮动操作条；
不会因侧栏滑块而扩大到整个页面布局。控制条及其祖先参与统一保留链，
退出时恢复原页面样式。网页全屏和小窗口播放共用开关组下方的单条提示卡片，
右上角可关闭；再次失败会重新显示，避免两条相同错误重复出现。

回归命令：

```sh
node --test test/*.test.cjs
node test/browser-controls.cjs
node test/browser-diagnostics.cjs
```

浏览器测试需外部 Playwright 与 Chromium 环境，覆盖普通/小窗口视口、操作条
延迟加载和重建、侧栏误匹配、退出清理，以及提示关闭、重试和开关回退。
这些是本地 DOM/模拟消息回归，不替代真实站点及扩展窗口 API 的集成测试。


### 国际化完整性与默认状态

32 种语言的全部 82 个界面键已对齐，包含播放错误正文、关闭按钮、提示标题、
起止时间及手动开启说明。语言包异步加载后，已显示的错误会按当前语言更新。
`node --test test/i18n.test.cjs` 检查重复键、漏键、占位符、代码引用和异步加载。

### 内容脚本失联恢复

用户主动开启网页全屏或小窗口时，若视频页没有回应，扩展会使用
`scripting` + `activeTab` 尝试在当前页恢复内容脚本，再重试原操作。
被浏览器限制或未获访问权限的页面仍显示本地化的刷新提示，不移动标签页。
读取状态不会注入脚本或自动开启；各模块及站点规则可安全重复注入。
预期的播放器诊断仅返回界面提示，非预期的浏览器 API 异常仍记录到后台。

扩展集成回归：`node test/browser-extension-connection.cjs`。
该测试使用临时扩展副本和独立 Chromium 配置，以本地测试站点权限模拟
工具栏点击获得的临时访问权限；模拟弹窗发送方，执行真实脚本注入和窗口 API，
覆盖未连接页面、重复注入、窗口往返及扩展重载后不刷新视频页的恢复。
